# 安全待办

2026-10-27。记录本轮之外的攻击面与后续验证，不表示这些措施已经实现。

## 本轮处理

- 图形安装向导统一程序和系统配置目录。Windows 使用系统路径 API、受保护 DACL 和管理员所有者；Unix 使用 root 所有权及 755/700/600 权限。用户 daemon 保持普通用户身份。
- 迁移保留原文件及受保护备份，校验密码配置、授权状态和 seal key 未改变，旧系统配置副本同时收紧权限。系统 shell 使用绝对路径，不搜索安装用户的 PATH。
- 凭据创建、导入、授权请求及执行器注入均拒绝 PATH、HOME、系统目录、代理、动态链接器、运行时启动钩子等通用环境变量。旧库可以读取、导出和删除这类键，但不可再次注入；不静默删除用户数据。
- 安装服务只监听临时 loopback 端口，要求精确 Host/Origin 和一次启动 token；提权 helper 只接受摘要绑定的固定操作计划，不接受任意命令或目标目录。不向 daemon 的 HTTP/MCP 接口增加安装执行能力。
